01 / COMPONENTS & DEVICES

Hardware field guide.

Understand the physical components of a computer, recognize common symptoms and learn safe first checks.

⏻POWER

Computer won't turn on

Possible causes include a disconnected power cable, depleted battery or power adapter issue.

Safe first checks

  1. Check the wall socket with a known working device.
  2. Ensure the power cable is firmly connected.
  3. For a laptop, connect its correct charger and wait a few minutes.
▣DISPLAY

Black screen / no signal

The display cable, monitor input, brightness or graphics hardware may be involved.

Safe first checks

  1. Confirm the monitor is powered on.
  2. Check the selected monitor input.
  3. Reconnect the display cable at both ends.
♨THERMAL

Overheating / loud fan

Blocked vents, dust buildup, heavy workloads or cooling problems can raise temperatures.

Safe first checks

  1. Place the computer on a hard, flat surface.
  2. Keep air vents unobstructed.
  3. Close demanding applications and allow it to cool.
▤STORAGE

Low storage space

A nearly full drive can prevent updates and reduce available space for temporary files.

Safe first checks

  1. Review storage usage in system settings.
  2. Back up important files before removing anything.
  3. Use the operating system's built-in cleanup utility.
▦MEMORY

Random freezes / restarts

Memory, overheating, drivers or unstable software may contribute to unexpected behavior.

Safe first checks

  1. Record when the freeze occurs.
  2. Install pending stable system updates.
  3. Run the operating system's built-in memory diagnostic if appropriate.
⌨PERIPHERALS

Keyboard or mouse not responding

Connection, battery, port or driver issues can interrupt input devices.

Safe first checks

  1. Check batteries on wireless devices.
  2. Try another USB port if available.
  3. Restart the computer and test again.
Important: Do not open a power supply, laptop battery or other high-voltage component. For internal repairs, use a qualified technician.
