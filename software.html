02 / OPERATING SYSTEM & APPS

Software field guide.

Common software issues, what they may mean and safe steps you can take before escalating the problem.

◴PERFORMANCE

Slow computer

Too many startup apps, low disk space, background tasks or malware can affect performance.

Safe first checks

  1. Restart the computer.
  2. Review startup apps and close unused programs.
  3. Check storage and run a trusted security scan.
⚠APPLICATIONS

Application keeps crashing

Outdated software, damaged files or compatibility issues may cause repeated crashes.

Safe first checks

  1. Note the application name and error message.
  2. Install updates from the official source.
  3. Restart and test; reinstall only after backing up data.
↻UPDATES

System update failure

Insufficient storage, interrupted connectivity or update service problems may prevent installation.

Safe first checks

  1. Keep the device connected to power.
  2. Check internet connection and free storage.
  3. Use the operating system's built-in update troubleshooter.
▧DRIVERS

Device not recognized

A missing, outdated or incompatible driver can stop hardware from working correctly.

Safe first checks

  1. Reconnect the device and restart.
  2. Check the system device manager for warnings.
  3. Get drivers only from the device maker or computer manufacturer.
▣BOOT

Operating system won't load

Startup configuration, damaged system files or storage issues may prevent booting.

Safe first checks

  1. Disconnect unnecessary external devices.
  2. Record any displayed error code.
  3. Use official recovery options and avoid formatting the drive.
⛨SECURITY

Suspicious pop-ups

Unwanted browser notifications, adware or malicious software may create unexpected pop-ups.

Safe first checks

  1. Do not click suspicious pop-ups.
  2. Review browser notification permissions.
  3. Run a scan using reputable security software.
Security reminder: Download software and drivers only from official or trusted sources. Never share passwords or one-time passcodes with support contacts.
